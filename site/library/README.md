# คลังเริ่มต้น

ไฟล์ในโฟลเดอร์นี้จะขึ้นเป็น **คลังเริ่มต้น** ของเว็บ เปิดเว็บมาก็เลือกชุดได้ทันทีโดยไม่ต้องเลือกโฟลเดอร์

ใส่เฉพาะไฟล์ที่คุณมีสิทธิ์เผยแพร่ เพราะทุกไฟล์ในนี้จะอยู่บนเว็บสาธารณะ

## โครงสร้าง (แบบเดียวกับ 3D_Export)

```
site/library/
  <ตัวละคร>/
    <ชื่อชิ้น>/
      <ชื่อ>.obj
      <ชื่อ>_texture.png     (ไม่มีก็ได้)
```

เช่น `site/library/Cat/Cat_scarf/Cat_scarf.obj` กับ `Cat_scarf_texture.png`

## หลังเพิ่มหรือลบไฟล์

push ตามปกติ workflow จะสร้าง `index.json` ใหม่ให้ตอน deploy
ถ้าจะทดสอบในเครื่อง ให้รัน `node scripts/build-library.mjs` ก่อน แล้วเปิด `python -m http.server -d site 8000`
