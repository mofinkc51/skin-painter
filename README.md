# Skin Texture Painter

เว็บสำหรับระบายสีพื้นผิว (texture) ของโมเดล `.obj` โดยเห็นผลบนโมเดล 3D ทันที แล้วบันทึกเป็น PNG ชื่อและขนาดเดิม เพื่อนำไปวางทับในเกม

ทั้งหมดทำงานในเบราว์เซอร์ ไฟล์ไม่ถูกอัปโหลดไปที่ไหน

## วิธีใช้

### คลังเริ่มต้น (ไฟล์ที่เผยแพร่ได้)

ไฟล์ที่วางไว้ใน `site/library/` จะขึ้นเป็นคลังเริ่มต้นทันทีที่เปิดเว็บ โดยไม่ต้องเลือกโฟลเดอร์ (เปิดชิ้นล่าสุดที่เคยใช้ หรือชิ้นแรกถ้าเพิ่งเข้ามาครั้งแรก)
โครงสร้างเหมือน 3D_Export: `site/library/<ตัวละคร>/<ชื่อชิ้น>/<ชื่อ>.obj` + `<ชื่อ>_texture.png`

- ใส่เฉพาะไฟล์ที่คุณมีสิทธิ์เผยแพร่ ไฟล์ทุกไฟล์ในนี้อยู่บนเว็บสาธารณะ
- push แล้ว workflow จะรัน `scripts/build-library.mjs` สร้าง `site/library/index.json` ให้เอง
- ทดสอบในเครื่อง: `node scripts/build-library.mjs` แล้ว `python -m http.server -d site 8000`
- ชี้ไปคลังอื่นได้ด้วย `?lib=<url ของ index.json>` ต่อท้ายลิงก์เว็บ

ในคลังชุดมีปุ่มสลับระหว่าง **คลังเริ่มต้น** กับ **โฟลเดอร์บนเครื่อง** (เช่น 3D_Export ที่ใช้ส่วนตัว)

### เปิดชุดจากโฟลเดอร์ 3D_Export (คลังชุด)

1. กด **คลังชุด** → **เลือกโฟลเดอร์ 3D_Export** (เลือกโฟลเดอร์ที่มีโฟลเดอร์ตัวละครอย่าง `Cat`, `Bat` อยู่ข้างใน)
2. เว็บจะจับคู่ `<ชื่อ>.obj` กับ `<ชื่อ>_texture.png` ในแต่ละโฟลเดอร์ให้อัตโนมัติ แล้วแสดงเป็นการ์ดพร้อมภาพตัวอย่าง
3. กรองตามตัวละคร ประเภท (ชุด / หัว / ของถือ / หลัง-ปีก — เดาจากชื่อไฟล์) หรือพิมพ์ค้นหาชื่อ แล้วกดการ์ดเพื่อเปิด
4. ใช้ปุ่ม ◀ ▶ (หรือ `Alt+←` / `Alt+→`) เพื่อเลื่อนไปชิ้นก่อนหน้า/ถัดไปโดยไม่ต้องเปิดคลังใหม่
5. ถ้าแก้ไขแล้วยังไม่บันทึก เว็บจะถามก่อนเปลี่ยนชิ้นเสมอ

ไฟล์ถูกอ่านในเบราว์เซอร์บนเครื่องเท่านั้น ไม่มีการอัปโหลด และ repo นี้ไม่มีไฟล์จากเกมอยู่ข้างใน

**Chrome / Edge** ทำได้เพิ่ม:
- จำโฟลเดอร์ไว้ ครั้งต่อไปกด **เปิดโฟลเดอร์เดิม** ได้เลย และจะเปิดชิ้นล่าสุดให้อัตโนมัติ
- **บันทึกลง _skins** เขียนไฟล์ไปที่ `3D_Export/_skins/<ตัวละคร>/<ชิ้น>/<ชื่อ>_texture.png` ไม่ทับไฟล์ต้นฉบับ
  ชิ้นที่มีไฟล์ใน `_skins` จะมีป้าย **แก้แล้ว** และเปิดเวอร์ชันที่แก้ไว้มาให้ทำต่อ (เครื่องมือคืนต้นฉบับยังใช้ภาพเกมเดิม)

เบราว์เซอร์อื่น (Firefox, Safari) ใช้คลังชุดได้ แต่ต้องเลือกโฟลเดอร์ใหม่ทุกครั้ง และบันทึกด้วยปุ่ม **บันทึก PNG** (ดาวน์โหลด)

ชิ้นที่ในเกมไม่มีไฟล์ `_texture.png` จะซ่อนไว้ก่อน ติ๊ก "เฉพาะชิ้นที่มีไฟล์ PNG" ออกเพื่อแสดง

### เปิดไฟล์ทีละคู่

กด **เปิดไฟล์เดี่ยว** แล้วเลือก `.obj` กับ `.png` พร้อมกัน (หรือลากมาวางในหน้า)

### ระบายสีและบันทึก

ระบายบนโมเดล 3D หรือบนภาพ PNG ฝั่งขวา อีกฝั่งจะอัปเดตตาม แล้วกด **บันทึก PNG** จะได้ไฟล์ชื่อเดิม ขนาดเดิม

| เครื่องมือ | ปุ่มลัด | ใช้ทำอะไร |
|---|---|---|
| พู่กัน | B | ระบาย เลือกหัวพู่กันและวิธีลงสีได้ |
| ยางลบ | E | ลบสิ่งที่ระบาย ให้กลับเป็นภาพต้นฉบับ (ปลายยางลบของปากกาก็ได้) |
| ถังสี | G | เติมทั้งชิ้นส่วน UV ที่คลิก หรือเฉพาะสีที่ใกล้เคียง |
| เปลี่ยนโทน | R | คลิกสีหนึ่ง ทุกจุดที่สีใกล้เคียงจะเปลี่ยนเป็นสีที่เลือก |
| ดูดสี | I หรือ Alt ค้าง | เก็บสีจากจุดที่คลิก |
| หมุนดู | V | หมุนโมเดลอย่างเดียว |

**หัวพู่กัน** (ปุ่ม 1–6): ปากกา · นุ่ม · พิกเซล · สเปรย์ · คราบ · เส้นเย็บ

**ลงสีแบบ**: ทับ · ย้อม (เก็บลายและแสงเงาเดิม, ปุ่ม T) · เงา · แสง · เบลอ · ป้าย — ใช้ได้ทั้งพู่กันและถังสี (ยกเว้นป้าย)

**เมาส์ปากกา**: รับแรงกดผ่าน Pointer Events ปรับได้ว่าแรงกดคุมขนาดเส้น ความทึบ หรือทั้งคู่ ตั้งขนาดตอนกดเบาและความไวแรงกดได้
ไม่รับนิ้วหรือฝ่ามือขณะใช้ปากกา, ปลายยางลบของปากกาเป็นยางลบ, ปุ่มข้างปากกาลากเพื่อเลื่อนภาพ
บน Windows ถ้าแรงกดไม่ขึ้น ให้เปิด Windows Ink ในโปรแกรมตั้งค่าของปากกา (Wacom, Huion, XP-Pen)

อื่น ๆ: `Shift`+คลิก ลากเส้นตรงจากจุดล่าสุด, `Alt+←` / `Alt+→` ชิ้นก่อนหน้า/ถัดไป, `Ctrl+Z` ย้อนกลับ, `Ctrl+Shift+Z` ทำซ้ำ, `[` `]` ย่อ/ขยายพู่กัน, ล้อเมาส์ซูม, คลิกขวาลากเพื่อเลื่อน

## โครงสร้าง

```
site/index.html                  ตัวเว็บทั้งหมด (ไฟล์เดียว, ใช้ three.js r128 จาก cdnjs)
site/library/                    คลังเริ่มต้น (.obj + _texture.png ที่เผยแพร่ได้)
scripts/build-library.mjs        สร้าง site/library/index.json จากไฟล์ในคลัง
.github/workflows/pages.yml      deploy โฟลเดอร์ site/ ไป GitHub Pages ทุกครั้งที่ push เข้า main
                                 (ต้นฉบับอยู่ที่ deploy/pages.yml สคริปต์ publish จะคัดลอกให้)
scripts/publish.ps1 / .sh        สร้าง repo บน GitHub, push และเปิด Pages ในครั้งแรก
```

## Publish ครั้งแรก

ต้องมี [git](https://git-scm.com) และ [GitHub CLI](https://cli.github.com) ที่ล็อกอินแล้ว (`gh auth login`)

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\publish.ps1
```

macOS / Linux / Git Bash:

```bash
scripts/publish.sh
```

สคริปต์จะสร้าง repo `skin-texture-painter` (public), push โค้ด, ตั้งค่า Pages ให้ deploy ผ่าน GitHub Actions แล้วสั่ง deploy รอบแรก
เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/skin-texture-painter/`

ถ้าเปิด Pages ผ่านสคริปต์ไม่สำเร็จ ให้ไปที่ **Settings → Pages → Source** แล้วเลือก **GitHub Actions**

## อัปเดตครั้งต่อไป

แก้ `site/index.html` แล้ว `git commit` + `git push` ตามปกติ workflow จะ deploy ให้เอง

## ทดสอบในเครื่อง

```bash
python -m http.server -d site 8000
```

แล้วเปิด http://localhost:8000
